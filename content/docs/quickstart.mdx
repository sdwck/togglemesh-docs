# Quickstart Guide

This guide will walk you through deploying your first ToggleMesh server via Docker Compose and evaluating a feature flag across multiple languages.

## Step 1: Start the ToggleMesh Server

ToggleMesh can be deployed anywhere using Docker. For this quickstart, we will use the Core Stack (PostgreSQL + Redis).

```bash
curl -o docker-compose.yml https://raw.githubusercontent.com/sdwck/ToggleMesh/main/docker-compose.yml
curl -o .env https://raw.githubusercontent.com/sdwck/ToggleMesh/main/.env.example
docker compose up -d
```

Once running, navigate to the Admin UI at `http://localhost:5264`. Create a new Project, a new Environment, and copy your **Server SDK API Key**.

## Step 3: Initialize the Client & Evaluate a Flag

ToggleMesh SDKs evaluate flags **locally** in memory using a Server-Sent Events (SSE) streaming connection to ensure zero-latency checks and immediate updates.

<Tabs items={['C# (.NET)', 'Node.js', 'Python', 'Go', 'React (Client)']} groupId="sdk">
  <Tab value="C# (.NET)">
    ```csharp
    // Program.cs
    builder.Services.AddToggleMeshClient(options => 
    {
        options.BaseUrl = "http://localhost:5264";
        options.ApiKey = "tm_server_xxxxxxxx";
    });
    builder.Services.AddToggleMeshHttpContext();

    // In your service
    public class CheckoutService(IToggleMeshClient toggleMesh)
    {
        public void ProcessOrder()
        {
            // Zero-allocation, local memory evaluation!
            if (toggleMesh.IsEnabled("new-checkout-flow", defaultValue: false))
            {
                ExecuteNewFlow();
            }
            else
            {
                ExecuteLegacyFlow();
            }
        }
    }
    ```
  </Tab>
  <Tab value="Node.js">
    ```javascript
    import { ToggleMeshClient } from 'togglemesh-node';

    const client = new ToggleMeshClient({
      baseUrl: 'http://localhost:5264',
      serverKey: 'tm_server_xxxxxxxx'
    });

    await client.start();

    // Local evaluation, no network request
    if (client.isEnabled('new-checkout-flow', false, { identity: 'user_123' })) {
      executeNewFlow();
    } else {
      executeLegacyFlow();
    }
    ```
  </Tab>
  <Tab value="Python">
    ```python
    from togglemesh import ToggleMeshClient, ToggleMeshOptions

    client = ToggleMeshClient(ToggleMeshOptions(
        base_url="http://localhost:5264",
        server_key="tm_server_xxxxxxxx"
    ))

    # Automatically syncs rules in background via SSE
    if client.is_enabled("new-checkout-flow", default_value=False, identity="user_123"):
        execute_new_flow()
    else:
        execute_legacy_flow()
    ```
  </Tab>
  <Tab value="Go">
    ```go
    import "github.com/sdwck/ToggleMesh/sdks/go/togglemesh"

    client, err := togglemesh.NewClient(
        togglemesh.WithBaseURL("http://localhost:5264"),
        togglemesh.WithAPIKey("tm_server_xxxxxxxx"),
    )
    if err != nil {
        panic(err)
    }
    defer client.Close()

    if client.IsEnabled("new-checkout-flow", togglemesh.WithIdentity("user_123")) {
        executeNewFlow()
    } else {
        executeLegacyFlow()
    }
    ```
  </Tab>
  <Tab value="React (Client)">
    ```tsx
    import { ToggleMeshClient } from 'togglemesh-js';
    import { ToggleMeshProvider, useFeatureFlag } from 'togglemesh-js/react';

    const client = new ToggleMeshClient({
      baseUrl: 'http://localhost:5264',
      clientKey: 'tm_client_xxxxxxxx'
    });

    client.identify('user_123', { Country: 'US' });

    function App() {
      return (
        <ToggleMeshProvider client={client}>
          <CheckoutComponent />
        </ToggleMeshProvider>
      );
    }

    function CheckoutComponent() {
      // Reacts in real-time to flag changes
      const isNewFlowEnabled = useFeatureFlag('new-checkout-flow', false);

      return isNewFlowEnabled ? <NewFlow /> : <LegacyFlow />;
    }
    ```
