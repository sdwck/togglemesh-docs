# Welcome to ToggleMesh Documentation

**ToggleMesh** is a self-hosted feature management and experimentation platform designed for teams requiring strict data privacy, enterprise-grade RBAC, and sub-30ns evaluation latency.

---

## ⚡ Key Highlights

- **Full Self-Hosting**: 100% control over your data plane and control plane.
- **Zero-Allocation Engine**: Microsecond-fast local memory evaluations without Garbage Collection pressure.
- **Real-Time Push**: Instant flag updates pushed over Server-Sent Events (SSE).
- **Multi-Language SDKs**: Native support for .NET (C#), Node.js, JS/React, Python, Go, Unreal Engine, and CLI.
- **Contextual Experiments**: Built-in Multi-Armed Bandit (MAB) auto-traffic allocation.
