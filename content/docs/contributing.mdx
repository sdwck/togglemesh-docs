# Contributing & Local Development

ToggleMesh is open-source. This guide covers how to run the core stack locally for development or contribution.

## Architecture Map

The ToggleMesh Core stack consists of several key components:

1. **The Core API**: A .NET 10 backend providing the REST API and SSE endpoints.
2. **The Admin UI**: A React application. When deployed via Docker, the built static files are served by the Core API. During local development, it runs as a standalone Vite process.
3. **PostgreSQL**: The primary database.
4. **Redis**: The caching layer and Pub/Sub mechanism that broadcasts flag changes across API nodes.
5. **ClickHouse & Kafka**: Advanced analytics and ingestion pipeline (available via `docker-compose.enterprise.yml`).

## Running Locally (Docker Compose)

You can spin up the stack locally using Docker Compose.

<Steps>
<Step>

### Clone the Repository

```bash
git clone https://github.com/sdwck/ToggleMesh.git
cd ToggleMesh
```

</Step>
<Step>

### Start the Stack

```bash
docker compose up -d
```

This starts PostgreSQL, Redis, and the ToggleMesh API node. Database migrations run automatically on startup (`TM_RUN_MIGRATIONS_ON_STARTUP=true`).

<Callout type="info" title="Alternative Compose Files">
- `docker-compose.dev.yml`: Spins up **only** the infrastructure dependencies (PostgreSQL, Redis) so you can run the API natively.
- `docker-compose.enterprise.yml`: Overrides the base compose to include ClickHouse and Kafka for the full enterprise stack.
</Callout>

</Step>
</Steps>

<Callout type="warning" title="Port Conflicts?">
If `localhost:5264`, `5432` (Postgres), or `6379` (Redis) are already in use, override them by editing the `.env` file before starting the stack:
```bash
TM_PORT=8080
POSTGRES_PORT=5433
REDIS_PORT=6380
```
</Callout>

### Accessing the UI & API Docs

Once containers report `service_healthy`:

- **Admin UI**: `http://localhost:5264`
- **API Docs (Scalar)**: `http://localhost:5264/docs`

Default Admin credentials:
- **Email**: `admin@togglemesh.local`
- **Password**: `Admin123!`

## Local Development (Without Docker for the API)

If you are modifying the .NET or React source code directly, run the infrastructure in Docker and the apps natively.

<Steps>
<Step>

### Start Infrastructure Dependencies

Use the dedicated development compose file to start only the database and caching layer:

```bash
docker compose -f docker-compose.dev.yml up -d
```

</Step>
<Step>

### Run the API Project

Open `ToggleMesh.sln` in Visual Studio or Rider and run the `ToggleMesh.API` project. 

It defaults to `https://localhost:7282` (or HTTP on `5264`) and connects to `localhost:5432` (Postgres) and `localhost:6379` (Redis). SDK clients should typically point to the HTTPS endpoint.

</Step>
<Step>

### Run the Admin UI

When running natively, the API node does not serve the Admin UI. You must start the React app manually:

```bash
cd src/ToggleMesh.AdminUI
npm install
npm run dev
```

The dashboard will be available at `http://localhost:5173`.

</Step>
</Steps>

## Contributing Guidelines

1. **Fork the Repository**: Create a fork and branch off `main`.
2. **Write Tests**: Ensure new features are covered in the `ToggleMesh.IntegrationTests` project.
3. **Submit a PR**: Provide a clear description of the problem and your proposed solution.
