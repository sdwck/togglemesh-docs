# Command Line Interface (CLI) Reference

The **ToggleMesh Universal CLI** is a powerful tool to synchronize feature flags directly from your Control Plane into your codebase. It can generate strongly-typed constants for **any supported language** (including C#, TypeScript, Python, and Go).

It does not matter which package manager you use to install the CLI (NPM, Pip, or .NET) — under the hood, they all run the exact same core engine. A Python developer can use `npm install -g togglemesh` or a Node developer can use `dotnet tool install`, and the behavior, features, and output will be **100% identical**.

The core high-performance CLI is also distributed as a native .NET Global Tool.

### Installation

```bash
dotnet tool install --global ToggleMesh.CLI
```

### Usage

```bash
# Launch the interactive configuration wizard
togglemesh config

# Synchronize feature flags and generate C# constants
togglemesh sync
```

The Go SDK includes a standalone Go CLI tailored specifically for `go generate` workflows.

### Installation

```bash
go install github.com/sdwck/ToggleMesh/sdks/go/cmd/togglemesh@latest
```

### Usage

The Go CLI is typically used via `go generate` directives, but can also be invoked manually.

```bash
# Launch the interactive configuration wizard
togglemesh config

# Synchronize feature flags manually
togglemesh sync -out flags.go -pkg main
```

**Go Directive Integration:**
```go
//go:generate togglemesh sync -out flags.go -pkg main
package main
```

**Go Specific Flags (`sync` and `config`)**:
| Flag | Type | Description |
| :--- | :--- | :--- |
| `-key` | `string` | API Key or PAT (saved globally in `~/.togglemesh`). |
| `-address` | `string` | Control Plane base URL (saved globally in `~/.togglemesh`). |
| `-project` | `string` | Project ID (saved locally in `.togglemesh/config.json`). |
| `-out` | `string` | Generated file path (default: `flags.go`). |
| `-pkg` | `string` | Package name for generated Go file (default: `main`). |

## Global CLI Flags (`sync`)

The `sync` command accepts several flags to override your configuration file or run in CI/CD environments. *(Note: Go CLI uses different flag names, see Go tab)*.

| Short | Long | Description |
| :--- | :--- | :--- |
| `-k` | `--api-key` | Environment API Key (`tm_server_...`) or PAT (`tmp_...`). |
| `-a` | `--address` | Control Plane base URL (e.g., `https://api.togglemesh.dev`). |
| `-l` | `--lang` | Target language (`csharp`, `typescript`, `go`, `python`). Auto-detected if omitted. |
| `-o` | `--out` | Output file path (e.g., `./src/flags.ts`). Auto-detected if omitted. |
| `-p` | `--project-id` | Project ID UUID (required when authenticating with a PAT). |
| `-y` | `--yes` | Non-interactive mode (automatically confirms prompts). |

<Callout type="info" title="Tip">
Running `togglemesh sync` without arguments automatically discovers your project language and writes to the default output path!
</Callout>
